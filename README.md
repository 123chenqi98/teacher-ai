## 🔎 项目简介
**EduMultimark** 是一款轻量化智能作业批改系统，依托多模态大模型、计算机视觉、自然语言处理与教育知识图谱技术，专为中小学全学段、多学科打造。

系统突破传统工具仅支持纯文字识别的局限，**全面兼容文字类、公式类、手绘类三大作业题型**，覆盖数学、物理、语文、英语、化学、生物等主流学科。依托十万余份标注数据集完成 LLaVA-13B 模型场景微调，文字识别准确率≥98%、公式识别准确率≥95%、手绘内容识别准确率≥92%，整体错误识别率控制在 4.2% 以内。

项目搭建**学生端、教师端、家长端**三端协同架构，不仅实现高速智能批改，还可基于学生错题数据构建个人知识点图谱，精准定位学习薄弱项，生成针对性解析与练习资源，形成「提交-批改-反馈-复习-监督」的完整学习闭环。本项目历经完整市场调研、竞品分析、多轮需求研讨，是一套技术成熟、场景落地性强、具备商业化潜力的教育AI项目。

## 🎯 项目背景
### 1. 行业核心痛点
我国K12阶段在校生规模超2亿，作业批改是教学核心环节，长期存在三大问题：
1. **批改效率低下**：中小学教师日均批改作业时长达到4.5~6小时，占用大量备课与授课时间；人工单份批改速度仅1.1份/分钟，效率极低。
2. **识别精度不足**：人工批改错误率高达30%，传统OCR技术综合识别率不足75%，无法精准识别数理公式、手绘图形类题目。
3. **个性化辅导缺失**：教师难以批量统计全班学情、定位每位学生的知识薄弱点，学生普遍存在盲目刷题、学习效率偏低的问题。

### 2. 政策与市场机遇
国家先后印发《教育数字化战略行动方案》《中小学教育数字化转型试点工作方案》，明确鼓励人工智能技术融入教学、减轻教师工作负担。目前国内教育信息化市场规模持续增长，智能作业批改工具整体渗透率不足10%，县域及农村中小学等下沉市场需求旺盛，轻量化、高性价比的智能教学工具存在巨大市场缺口。

### 3. 项目建设目标
以**技术赋能教育数字化转型，让每一份作业都产生个性化价值**为核心理念，打造无需专用硬件、适配低配置终端的智能批改系统，降低技术使用门槛，助力城乡教育资源均衡发展。

## 📋 前期筹备工作
项目正式开发前，团队完成全流程前期调研与论证工作，确保产品贴合市场与教学需求：

### 1. 全域市场调研
2024年3-5月，历时3个月开展实地调研，覆盖广西、广东、湖南3省6市12县，走访30所中小学、20家教育培训机构，累计调研一线教师200名、学生500名、家长300名。
调研结果显示：超9成教师希望借助工具缩减批改时长，理科教师对公式、手绘识别需求强烈；多数学生期望获得清晰解析与个性化练习；学校及机构优先关注产品易用性与使用成本。

### 2. 多轮团队研讨
项目执行期间开展常态化会议研讨，覆盖四大方向：
1. 需求研讨：梳理全业务流程，确定三端功能清单、交互逻辑与权限体系；
2. 技术研讨：敲定模型选型、图像处理方案、前后端架构、数据存储规则；
3. 版本迭代研讨：根据用户反馈制定产品迭代计划，持续优化功能体验；
4. 落地研讨：对接试点学校，确定部署方案、培训流程与运维规范。

### 3. 竞品分析
团队对市面上主流智能作业批改产品开展横向对比，将竞品分为头部互联网产品、传统教育信息化产品、新兴创业产品三类，并梳理各自短板：
1. 头部平台：侧重C端用户，校园适配能力弱，手绘识别准确率不足80%，收费标准偏高；
2. 传统教育软件：依赖老旧OCR技术，错误率≥15%，缺少个性化学情分析能力；
3. 初创产品：题型覆盖单一，仅支持文字批改，部署成本高，难以规模化推广。

本项目以**多模态全题型覆盖、轻量化部署、高性价比、B/C端协同**作为核心差异化优势，重点布局下沉市场。

## 🧱 整体技术架构
系统采用**五层分层架构**，模块解耦、逻辑清晰，兼顾扩展性与稳定性，整体流程：`采集层 → 预处理层 → 批改层 → 反馈层 → 应用层`

1. **采集层**
    支持手机、电脑多终端作业上传，具备自动裁剪、亮度调节功能；图像统一压缩至500KB以内并转为JPG格式，适配Android、iOS低配置手机与弱网络环境，节省流量与存储资源。

2. **预处理层**
    基于 OpenCV 实现图像倾斜矫正、模糊修复；通过 Mathpix 提取数理公式；采用 U-Net 语义分割模型定位手绘区域，将作业拆分为文字块、公式块、手绘块，为精准识别奠定基础。

3. **批改层**
    以微调后的 LLaVA-13B 多模态大模型为核心，搭配自定义评分规则引擎；客观题自动匹配答案，主观题实现按步骤扣分、标注错误原因，同时支持教师人工二次调整分数。

4. **反馈层**
    依托 Neo4j 教育知识图谱，自动生成错题解析、知识点说明；结合ECharts制作知识点雷达图、薄弱模块分析报告，并智能匹配同类例题与拓展练习。

5. **应用层**
    面向教师、学生、家长提供独立交互入口，三端数据实时互通，覆盖作业管理、学情统计、学习监督等全场景。

## 🧩 核心模块说明
本项目代码仓库整体划分为**前端、后端、多模态模型、数据分析**四大独立模块，模块间通过接口互联互通：

### 1. 前端模块（Frontend）
分为三大客户端，采用现代化技术开发，轻量化、易上手：
- **教师Web端**：基于 Vue3 + Element Plus 开发，支持作业批量上传、批量批改、分数调整、成绩单导出、标准答案管理等功能。
- **学生移动端**：基于 Flutter 开发，支持作业拍摄上传、错题本管理、错题重做、解析查看、专项练习。
- **家长小程序端**：微信轻量化小程序，可实时查看学生学习报告、薄弱知识点与复习进度，支持师生留言沟通。

### 2. 后端模块（Backend）
基于 Python 搭建服务集群，承担业务调度、接口转发、权限管控、文件管理、数据加密等工作，适配断点续传，兼容弱网络场景，保障全终端稳定访问。

### 3. 多模态模型模块（Model）
项目核心AI模块：
- 基础模型：LLaVA-13B 多模态大模型，使用10万+份中小学标注作业数据集完成场景微调；
- 核心能力：文字识别、公式解析、手绘图形识别、主观题分步判分；
- 优化方向：模型轻量化改造，降低硬件部署门槛，普通服务器即可稳定运行。

### 4. 数据分析模块（Data Analysis）
负责全维度学习数据处理与可视化：
- 数据统计：班级错题分布、知识点错误率、学生成绩趋势分析；
- 特征归因：定位个人知识薄弱点，生成可视化分析报表；
- 资源匹配：关联知识图谱，自动推送匹配例题与复习资料；
- 报表导出：支持多格式学习报告、班级学情报告生成与导出。

## ✨ 核心功能与产品特点
### 一、核心功能
结合五层架构，系统实现全流程业务能力：
1. 多终端作业采集、自动图像处理与格式统一；
2. 文字、公式、手绘全题型智能识别与自动批改；
3. 客观题自动判分、主观题按步骤扣分并标注错误原因，支持教师人工干预；
4. 错题自动归档、结构化解析生成与个性化练习推送；
5. 个人知识点图谱、班级学情统计与可视化报告；
6. 三端数据互通，满足学生学习、教师管理、家长监督需求。

### 二、核心产品特点
1. **多模态全场景覆盖**
    同时支持文字、公式、手绘三大类作业，覆盖中小学九大学科，解决传统产品题型单一的问题。
2. **高效与精度双重保障**
    系统批改速度可达105份/分钟，相比人工提升90倍以上；综合错误识别率仅4.2%，主观题步骤扣分精准度≥91.5%。
3. **个性化学习闭环**
    构建「批改-解析-定位-复习-巩固」完整体系，精准定位薄弱知识点，避免盲目刷题，有效提升学习效率。
4. **轻量化易部署**
    无需专用扫描设备与高配置终端，普通手机、电脑即可使用，适配低配置设备与农村地区网络环境。
5. **数据安全合规**
    严格遵循《个人信息保护法》《教育数据管理办法》，采用加密存储、分级权限、匿名化处理等方式，全方位保护师生隐私数据。

## 🚀 环境部署与运行
### 前置环境要求
1. 硬件：服务器最低配置8G内存，推荐16G及以上（保障多模态模型正常运行）；
2. 基础环境：Python 3.9+、Node.js 18+、MySQL 8.0、Git、Docker；
3. 可选配置：安装 CUDA，可大幅提升模型推理速度。

### 1. 克隆项目代码
```bash
git clone https://github.com/123chenqi98/teacher-ai.git
cd teacher-ai
```
### 2. 后端服务启动（Windows 终端 / PowerShell）
```bash
# 创建Python虚拟环境
python -m venv venv

# 激活虚拟环境
venv\Scripts\activate

# 安装后端依赖库
pip install -r backend/requirements.txt

# 启动后端服务
python backend/main.py
```
### 3. 多模态模型服务启动
```bash
# 进入模型目录
cd model

# 加载微调模型，启动推理服务
python model_server.py
```
### 4. 教师 Web 前端启动
```bash
# 进入前端目录
cd frontend

# 安装前端依赖
npm install

# 启动前端开发服务
npm run dev
```
### 5. 移动端 & 小程序
按照 Flutter、微信小程序官方编译流程完成打包、部署与运行即可。
