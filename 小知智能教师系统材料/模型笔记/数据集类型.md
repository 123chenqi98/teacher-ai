这些数据集可以按**大模型训练阶段 / 任务类型**分为以下几类：

### 1. 指令微调数据集（单轮任务）

- **代表**：`alpaca_en_demo.json`、`alpaca_zh_demo.json`
- 类型说明：是最常见的指令微调（Instruct Tuning）数据，格式为「指令 + 输入 + 输出」，用于训练模型理解并执行单轮任务（如翻译、问答、总结）。

### 2. 预训练语料数据集

- **代表**：`c4_demo.json`
- 类型说明：属于大规模无标注文本语料（来自 Common Crawl 网页），用于语言模型的预训练阶段，帮助模型学习语法、语义和通用知识。

### 3. 偏好对齐数据集（优化人类偏好）

- **代表**：`dpo_en_demo.json`、`dpo_zh_demo.json`、`v1_dpo_demo.json`、`kto_en_demo.json`
- 类型说明：
  - **DPO 类**：包含「指令 + 优质回答 + 劣质回答」，用于直接偏好优化（让模型生成更符合人类偏好的内容）；
  - **KTO 类**：包含「指令 + 回答 + 布尔标签（是否接受）」，通过二元反馈优化模型行为，比 DPO 更简化。

### 4. 教育场景专用数据集

- **代表**：`educhat_train.json`
- 类型说明：是教育领域的对话 / 任务数据集，用于训练教育场景的大模型（如解题、答疑）。

### 5. 工具调用数据集

- **代表**：`glave_toolcall_en_demo.json`、`glave_toolcall_zh_demo.json`、`reason_tool_use_demo_50.jsonl`
- 类型说明：用于训练模型调用外部工具 / 执行复杂推理（如调用 API、逻辑推理、多步骤任务）。

### 6. 多模态数据集（跨模态任务）

- **代表**：`mllm_audio_demo.json`、`mllm_video_demo.json`、`mllm_video_audio_demo.json`
- 类型说明：属于多模态大模型（MLLM）的训练数据，包含文本 + 音频 / 视频等跨模态内容，用于训练模型理解不同模态信息。

### 7. 监督微调数据集（基础微调）

- **代表**：`v1_sft_demo.jsonl`
- 类型说明：是监督微调（SFT）数据，通过「输入 + 目标输出」的配对，让模型学习特定任务的基础能力。



[dataset_info.json](file:///E:/EduChat/LLaMA-Factory/data/dataset_info.json) 包含了所有可用的数据集。如果您希望使用自定义数据集，请**务必**在 `dataset_info.json` 文件中添加*数据集描述*，并通过修改 `dataset: 数据集名称` 配置来使用数据集。
