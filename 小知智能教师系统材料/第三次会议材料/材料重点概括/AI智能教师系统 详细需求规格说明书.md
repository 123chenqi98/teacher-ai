# AI智能教师系统

## 详细需求规格说明书



### 1、定义与术语

| 术语       | 定义                                                         |
| :--------- | :----------------------------------------------------------- |
| 九章大模型 | 好未来自研的教育专用大模型，在数学推理和知识图谱构建方面具有差异化优势 |
| DeepSeek   | 通用大语言模型，负责通用知识问答和自然语言理解               |
| K12        | 指从幼儿园到十二年级的教育体系，即基础教育阶段               |
| 学情分析   | 对学生学习情况的全面分析，包括知识掌握度、学习进度、学习习惯等 |
| 个性化教学 | 根据学生的个体差异提供定制化的教学内容和方法                 |
| 智能批改   | 利用AI技术自动批改作业，包括客观题和主观题                   |
| 备课助手   | 帮助教师快速完成备课工作的AI工具                             |

### 2、 需求背景

SRS 明确要求系统采用 “九章大模型（教育专用）+DeepSeek（通用）” 双引擎架构，需实现**数学文字题批改正确率≥97%、英语作文批改准确率≥98%** ，且支持 “30 秒生成简单教案、2 分钟生成复杂教案” 的效率目标。同时需覆盖 K12 全学科（语文 / 数学 / 英语 / 物理 / 化学等），解决现有产品 “理科知识点错误频发、文科深度评价不足” 的痛点。

### （**初期只需要实现批改正确率在75%以上，后续再逐步提高正确率**，K12学科可先从语文、数学和英语入手）

### 3、功能需求优先级

根据调研数据和市场分析，将功能需求分为三个优先级：

| 优先级   | 功能类别   | 具体功能                     | 需求占比 | 业务价值            |
| :------- | :--------- | :--------------------------- | :------- | :------------------ |
| 高优先级 | 智能备课   | 教案生成、课件制作、资源整合 | 37%+     | 节省备课时间50%以上 |
| 高优先级 | 作业批改   | 全学科智能批改、作文批改     | 81.2%    | 提升批改效率60%以上 |
| 高优先级 | 学情分析   | 知识点掌握分析、学习行为分析 | 76.5%    | 精准定位学习问题    |
| 高优先级 | 智能答疑   | 24小时问答、解题思路引导     | 63.8%    | 提升学习效果        |
| 中优先级 | 个性化教学 | 自适应学习路径、分层作业     | 63.8%    | 满足差异化需求      |
| 中优先级 | 课堂互动   | 点名、投票、实时反馈         | 35%      | 增强课堂参与度      |
| 低优先级 | 教学管理   | 课程安排、成绩统计、报表生成 | 25%      | 提升管理效率        |
| 低优先级 | 家校互动   | 消息推送、通知发布、沟通记录 | 30%      | 促进家校协同        |
