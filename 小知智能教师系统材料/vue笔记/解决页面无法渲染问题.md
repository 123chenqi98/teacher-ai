路由父组件是否包含子路由出口！！！

```vue
<template>
  <el-container style="min-height:100vh">
    <router-view />
  </el-container>
</template>

<script setup lang="ts">
// 用户中心与首页的父容器，渲染子路由
</script>

<style scoped>
</style>
```

核心结论是：**父组件必须包含子路由出口（如 Vue 的 `<router-view>`、React Router 的 `<Outlet>`），子路由对应的组件才能正常渲染**。

### 关键原因

1. 子路由出口是子组件的 “挂载点”，没有这个出口，路由器无法确定子组件该渲染到父组件的哪个位置。
2. 父组件若缺失出口，子路由匹配后只会触发路由状态变化，不会在页面上呈现子组件内容，导致 “路由跳转成功但页面无变化”。

### 补充说明

不同框架的子路由出口语法不同，但核心作用一致。Vue 中用 `<router-view>`，React Router v6+ 用 `<Outlet>`，Angular 用 `<router-outlet>`
