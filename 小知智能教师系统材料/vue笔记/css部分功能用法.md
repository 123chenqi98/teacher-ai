这个 CSS 类是你导航栏布局根容器的样式，三个属性共同作用于 `<div class="teacher-dashboard">`（组件最外层容器），核心是**实现 “全屏高度 + 水平分栏 + 统一字体” 的基础布局**，下面逐个拆解属性的作用和实际效果：

### 1. `display: flex;`：核心布局逻辑（水平分栏）

结合你的组件结构（左侧 `<el-aside>` 侧边栏 + 右侧 `<main>` 主内容区），这个属性的作用是：

- 让 `.teacher-dashboard` 成为**弹性容器**，其直接子元素（`<el-aside>` 和 `<main>`）成为**弹性项目**；
- 弹性项目默认沿**水平方向（主轴）排列**，实现 “左侧侧边栏 + 右侧主内容区” 的并排布局（不用 float 或 position，更简洁稳定）；
- 后续可通过 `flex` 相关属性控制两个区域的宽度分配（比如侧边栏固定 240px，主内容区自适应占满剩余空间）。

#### 实际效果：

没有 `display: flex;` 时，`<el-aside>` 和 `<main>` 会默认垂直堆叠（块级元素特性）；加上后会自动水平并排，正是你导航栏 “左右分栏” 的核心实现。

### 2. `min-height: 100vh;`：全屏高度保障

- 先解释单位：`vh` 是 “视口高度” 的单位，`100vh` = 浏览器可视区域的 100% 高度（比如屏幕高 1080px，`100vh` 就是 1080px）；
- `min-height` 表示 “最小高度”：容器的高度**至少**是屏幕可视区域的 100%，如果页面内容不足 100vh，容器会自动拉伸到全屏；如果内容超过 100vh，容器会跟随内容自动增高（不会出现内容溢出或底部空白）。

#### 为什么不用 `height: 100vh;`？

- `height: 100vh;` 是 “固定高度”：如果页面内容太多（比如主内容区有大量教案、数据），内容会超出容器高度，导致滚动条异常；
- `min-height: 100vh;` 更灵活：既保证了 “内容少的时候占满屏幕”，又支持 “内容多的时候自动延伸”，是页面布局的常用最佳实践。

#### 实际效果：

你的导航栏布局会默认占满整个屏幕高度，左侧侧边栏和右侧主内容区一起撑满页面，不会出现 “顶部有导航、底部空白” 的情况。

### 3. `font-family: 'Inter', system-ui, sans-serif;`：统一字体样式

- 作用：为 `.teacher-dashboard` 及其所有子元素（侧边栏菜单、顶部导航文字、主内容区文字等）统一设置字体；
- 字体栈解析（优先级从左到右）：
  1. 优先使用 `'Inter'` 字体（现代无衬线字体，清晰易读，常用于后台管理系统）；
  2. 如果用户设备没有安装 `Inter`，则使用 `system-ui`（系统默认的无衬线字体，比如 Windows 的 “微软雅黑”、Mac 的 “SF Pro”）；
  3. 最后用 `sans-serif` 兜底（所有浏览器都支持的无衬线字体，确保字体不会错乱）。
