# 基座模型

### 1、**教案生成：师承万象基础教育大模型**：

该模型是国内首个紧扣新课标知识体系的基础教育大模型，堪称教案生成场景的优选基座模型。其研发过程中系统整合了教材、教案等多元教育资源构建训练数据，还通过继续预训练、指令微调等训练路径，实现了对课程标准内涵的深度理解。它推出的教案生成助手能兼容多种教材版本，支持符合新课程标准要求的多样化教学模式，可直接生成契合现代教学理念的教学方案，精准匹配教师撰写教案时对专业性、贴合性的核心需求，在同等规模参数量大模型中教育专业能力综合表现排名第一。 

### 2、作业批改：Qwen3 - Learning

作为阿里专为学习场景打造的强适配模型，它基于万亿级教育数据训练，融合海量真题，适配从小学到大学的全学段、全学科作业批改。不仅能精准识别印刷体与手写体，完成语文阅读题、数学应用题等多种题型批改，还能在批改后生成包含薄弱点诊断、错题深度讲解的智能小结，形成学习闭环，尤其适合日常全学科作业的规模化、精细化批改。   

### 3、**教育对话：EduChat - R1**：

这是具备“教育思维链”的混合推理教育大模型，是教育对话场景的理想基座模型。它引入独特的教育思维链机制，秉持“Thinking before teaching”理念，能模拟人类教师的教学决策过程。在教育对话中，它可通过苏格拉底式引导与学生互动，比如针对学生的疑问，不是直接给出答案，而是通过提问逐步启发思考；面对心理疏导类对话，还能融合多种心理咨询理论提供帮助。而且该模型在多学科中具备个性化教学方案输出能力，可根据学生知识水平调整对话和辅导节奏，同时支持调用教育工具，适配课后答疑、学习引导等多种教育对话场景，目前还开源了多个参数版本，便于进一步适配定制。
