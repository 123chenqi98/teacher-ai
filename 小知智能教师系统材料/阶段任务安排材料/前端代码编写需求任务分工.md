## 系统通用模块（全端共用）



### 1. 登录 / 注册页面

- 账号密码登录（支持手机号 / 用户名）
- 验证码登录（短信验证码获取与验证）
- 第三方登录（微信、QQ 快捷登录）
- 忘记密码（手机号验证 + 密码重置流程）
- 注册功能（教师 / 学生 / 家长角色选择，信息完善）
- 记住密码勾选框 + 自动登录选项
- 登录状态保存与过期自动退出
- 表单验证（格式校验、必填项提示、错误反馈）

### 3. 个人中心页面

- 基本信息展示（姓名、角色、手机号、头像等）
- 信息编辑功能（修改昵称、手机号、密码、头像上传）
- 账号安全设置（登录密码修改、绑定手机号变更、登录日志查看）
- 个性化设置（主题切换、语言选择、通知权限设置）
- 我的收藏（收藏的教案、资源、习题管理）
- 操作历史记录（近期使用功能足迹展示）

## 系统管理模块（后台管理端）

### 1. 用户管理页面

- 用户列表展示（用户名、角色、手机号、状态、创建时间）
- 多条件筛选（角色、状态、学科、年级）
- 搜索功能（支持用户名、手机号搜索）
- 用户操作（新增、编辑、禁用 / 启用、删除、重置密码）
- 批量操作（批量禁用、批量导出）
- 用户详情查看（基本信息、角色权限、操作日志）

### 2. 角色权限页面

- 角色列表（角色名称、描述、权限范围、创建时间）
- 角色操作（新增、编辑、删除）
- 权限分配（树形权限选择、全选 / 反选、权限预览）
- 自定义角色创建（自定义权限组合）
- 角色复制功能

### 3. 数据统计页面

- 系统运营概览（总用户数、活跃用户数、各端使用占比）
- 功能使用统计（各模块访问次数、使用频率排行）
- 数据图表展示（柱状图、饼图、折线图切换）
- 数据筛选（时间范围、区域、学校）
- 统计报告生成与导出（Excel、PDF）
- 数据导出权限控制

### 4. 系统设置页面

- 基础设置（系统名称、logo 上传、版权信息）
- 安全设置（登录失败次数限制、密码有效期设置）
- 通知设置（短信模板、邮件模板编辑）
- 资源管理（教学资源审核、分类管理）
- 日志管理（系统日志、操作日志、异常日志查看与导出）
- 缓存清理功能
- 版本更新记录展示

### 5. 学科 / 年级管理页面

- 学科列表（学科名称、编码、状态、排序）
- 年级列表（年级名称、对应学段、排序）
- 教学大纲管理（按学科 / 年级上传、编辑、查看教学大纲）
- 学期管理（新增学期、设置当前学期、学期状态切换）
- 批量导入 / 导出功能
